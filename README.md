# Patel Voice Assistant 🎙️

An AI-powered desktop voice assistant built using Python and Gemini API.

## Features
- Voice recognition for user commands
- Powered by Google Gemini API
- Custom music library integration
- Easy-to-use desktop assistant interface

## Requirements
- Python 3.x
- Required libraries listed in project script
